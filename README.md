## უმარტივესი გზა: ინსტალერი

Python-ის, Git-ის და ტერმინალის გარეშე. ყველაფერი (Python-იც) ინსტალერშია ჩაშენებული.

1. გახსენით [Releases](https://github.com/Darbazi-A/live-translate/releases/latest) და ჩამოტვირთეთ:
   - **Windows 10/11:** `LiveTranslate-Setup-x.y.z.exe`
   - **macOS (Apple Silicon, M1 და უფრო ახალი):** `LiveTranslate-mac-x.y.z.dmg`
2. **Windows:** გაუშვით Setup-ი → Next → Install. ინსტალერი თვითონ უშვებს ტელეფონებს Firewall-ში, ქმნის ხატულას Desktop-ზე და Start მენიუში.
   ⚠️ თუ გამოჩნდა **„Windows protected your PC“** (SmartScreen): **More info → Run anyway**. ეს ჩნდება, რადგან ინსტალერი ციფრული სერტიფიკატით არ არის ხელმოწერილი.
3. **macOS:** გახსენით `.dmg` და გადაათრიეთ **Live Translate** ხატულა **Applications**-ში.
   ⚠️ პირველ გაშვებაზე macOS იტყვის, რომ დეველოპერი დაუდასტურებელია: **System Settings → Privacy & Security → Open Anyway**. ერთხელ საკმარისია.
4. გაუშვით **Live Translate**. სპიკერის გვერდი Chrome-ში თავისით გაიხსნება. Windows-ზე ჩანს შავი ფანჯარაც მისამართებით: ის ღონისძიების განმავლობაში ღია უნდა დარჩეს. macOS-ზე პროგრამა ფონზე მუშაობს და ითიშება სპიკერის გვერდიდან: **პარამეტრები → სერვერის გამორთვა**.

სპიკერის კომპიუტერზე **Google Chrome** უნდა იყოს (ხმის ამოცნობისთვის). მსმენელებს არაფერი სჭირდებათ.

თუ ინსტალერი არ გამოგადგათ, ქვემოთ აღწერილია გაშვება Python-ით.

## 1. Python-ის დაყენება

ჯერ შეამოწმეთ, ხომ არ აყენია უკვე. გახსენით ტერმინალი (Windows-ზე: **Start** → ჩაწერეთ `cmd` → Enter; macOS-ზე: **Terminal**) და ჩაწერეთ:

```bash
python --version
```

macOS-სა და Linux-ზე ჩაწერეთ `python3 --version`. თუ ჩანს `Python 3.10` ან უფრო ახალი (მაგ. `Python 3.12.10`), ეს ნაბიჯი გამოტოვეთ.

### Windows 10/11

**ვარიანტი A: ოფიციალური საიტიდან (რეკომენდებული)**

1. გახსენით [python.org/downloads](https://www.python.org/downloads/) და დააჭირეთ **Download Python 3.x**.
2. გაუშვით ჩამოტვირთული ფაილი.
3. ⚠️ ინსტალერის პირველ ფანჯარაში, ქვემოთ, **მონიშნეთ „Add python.exe to PATH“**. ამის გარეშე `start.bat` Python-ს ვერ იპოვის.
4. დააჭირეთ **Install Now** და დაელოდეთ დასრულებას.
5. **დახურეთ და თავიდან გახსენით** ტერმინალი, შემდეგ შეამოწმეთ: `python --version`

**ვარიანტი B: ბრძანებით (winget)**

```bash
winget install -e --id Python.Python.3.12
```

ამის შემდეგ ტერმინალი დახურეთ და თავიდან გახსენით.

> თუ `python` ბრძანება **Microsoft Store**-ს ხსნის, ეს Windows-ის „ცარიელი“ მალსახმობია და არა Python. დააყენეთ Python ზემოთ აღწერილი გზით. თუ ამის შემდეგაც Store იხსნება: **Settings → Apps → Advanced app settings → App execution aliases** → გამორთეთ `python.exe` და `python3.exe`.

### macOS

**ვარიანტი A: ოფიციალური საიტიდან**

1. გახსენით [python.org/downloads](https://www.python.org/downloads/) და ჩამოტვირთეთ macOS-ის ინსტალერი (`.pkg`).
2. გაუშვით და მიჰყევით ნაბიჯებს.
3. შეამოწმეთ Terminal-ში: `python3 --version`

**ვარიანტი B: Homebrew-ით** (თუ [Homebrew](https://brew.sh) უკვე გაქვთ)

```bash
brew install python
```

### Linux (Ubuntu / Debian)

```bash
sudo apt update
sudo apt install python3 python3-venv python3-pip
```

`python3-venv` აუცილებელია, რადგან `start.sh` საჭირო პაკეტს ცალკე, პროექტის საქაღალდეში აყენებს.

Fedora-ზე: `sudo dnf install python3`

## 2. Git-ის დაყენება (ან ZIP-ით ჩამოტვირთვა)

შეამოწმეთ: `git --version`. თუ ვერსია ჩანს, ეს ნაბიჯი გამოტოვეთ.

| სისტემა | დაყენება |
|---|---|
| **Windows** | [git-scm.com/download/win](https://git-scm.com/download/win) → ჩამოტვირთეთ და დააყენეთ ნაგულისხმევი პარამეტრებით (Next → Next…). ან ბრძანებით: `winget install -e --id Git.Git` |
| **macOS** | Terminal-ში: `xcode-select --install` (დააჭირეთ Install-ს), ან `brew install git` |
| **Linux** | `sudo apt install git` (Fedora: `sudo dnf install git`) |

დაყენების შემდეგ ტერმინალი დახურეთ და თავიდან გახსენით.

**Git-ის გარეშე:** გახსენით [github.com/Darbazi-A/live-translate](https://github.com/Darbazi-A/live-translate) → მწვანე ღილაკი **Code** → **Download ZIP** → ამოარქივეთ (Windows: მარჯვენა ღილაკი → **Extract All**).

## 3. პროექტის ჩამოტვირთვა

ტერმინალში გადადით საქაღალდეში, სადაც პროექტი გინდათ (მაგ. Desktop), და ჩამოტვირთეთ:

```bash
cd Desktop
git clone https://github.com/Darbazi-A/live-translate.git
```

შედეგად შეიქმნება საქაღალდე `live-translate`.

## 4. გაშვება

### Windows

გახსენით `live-translate` საქაღალდე და **ორჯერ დააჭირეთ `start.bat`-ს**.

პირველ გაშვებაზე ის საჭირო პაკეტს (`edge-tts`) თვითონ დააყენებს, რასაც რამდენიმე წამი სჭირდება. შემდეგ ფანჯარაში გამოჩნდება:

```
  Live Translate is running

  Speaker (this computer, Chrome):  http://localhost:8000/speaker
  Listener (this computer):         http://localhost:8000/listen
  Listener (phones on same Wi-Fi):  http://192.168.1.25:8000/listen
```

⚠️ პირველ გაშვებაზე **Windows Firewall** იკითხავს, დაუშვას თუ არა Python-ს ქსელთან წვდომა. მონიშნეთ **Private networks** და დააჭირეთ **Allow access**. ამის გარეშე ტელეფონები ვერ დაუკავშირდებიან.

**ეს ფანჯარა ღონისძიების განმავლობაში ღია უნდა დარჩეს.** მის დახურვას სერვერი გაჩერდება.

### macOS / Linux

Terminal-ში:

```bash
cd ~/Desktop/live-translate
sh start.sh
```

პირველ გაშვებაზე შეიქმნება `.venv` საქაღალდე, სადაც საჭირო პაკეტი დაყენდება. ეს ერთხელ ხდება.

- **macOS:** თუ იკითხავს „Do you want the application python to accept incoming network connections?“, დააჭირეთ **Allow**.
- **Linux:** თუ ფაიერვოლი (ufw) ჩართულია: `sudo ufw allow 8000/tcp`

### გაჩერება

ფანჯარაში დააჭირეთ **Ctrl+C**, ან უბრალოდ დახურეთ ფანჯარა.

### სხვა პორტი

თუ 8000 პორტი დაკავებულია, სერვერი თვითონ აიღებს შემდეგ თავისუფალს (8001, 8002…) და ფანჯარაში სწორ მისამართს დაწერს. თუ კონკრეტული პორტი გინდათ:

- **Windows** (cmd, პროექტის საქაღალდეში): `set PORT=8080` და შემდეგ `start.bat`
- **macOS / Linux:** `PORT=8080 sh start.sh`

## 5. ღონისძიებაზე: სპიკერი და მსმენელები

**სპიკერი** (სერვერის კომპიუტერზე):

1. სერვერის გაშვებისას გვერდი Chrome-ში თავისით იხსნება. თუ არა, გახსენით http://localhost:8000/speaker
2. აირჩიეთ ენა (**ქართული → EN**), რეჟიმი (**ბალანსი**) და **მიკროფონი** (სიიდან, თუ რამდენიმე გაქვთ).
3. დააჭირეთ მიკროფონის ღილაკს (ან **Space**). პირველ ჯერზე Chrome იკითხავს მიკროფონის ნებართვას, დააჭირეთ **Allow**. ღილაკის ირგვლივ რგოლი ხმასთან ერთად მოძრაობს: ასე ჩანს, რომ მიკროფონი გესმით.
4. ილაპარაკეთ. მარჯვნივ ჩანს, რა ამოიცნო და როგორ ითარგმნა. ზემოთ, მწვანე ნიშანი **„თარგმანი · ms“** აჩვენებს, რომ თარგმანი მუშაობს.
5. **პროექტორზე** ღილაკი QR კოდს მთელ ეკრანზე აჩვენებს მსმენელებისთვის.

სპიკერის გვერდი აუცილებლად **ამავე კომპიუტერზე, `localhost` მისამართით** უნდა გაიხსნას. Chrome მიკროფონს სხვა მისამართზე (`http://192.168…`) არ რთავს.

**მსმენელები:**

1. დაუკავშირდნენ **იმავე Wi-Fi-ს**, რომელზეც სერვერის კომპიუტერია.
2. ტელეფონის კამერით დაასკანერონ **QR კოდი**, რომელიც სპიკერის გვერდის ბოლოშია (მისი ეკრანზე ან პროექტორზე ჩვენება შეიძლება), ან ხელით გახსნან ბმული `http://<კომპიუტერის-IP>:8000/listen`.
3. აირჩიონ ენა (**English**) და დააჭირონ **Start listening** (ან **Read captions only**, თუ ხმა არ სჭირდებათ).
4. ქვედა პანელიდან შეუძლიათ ხმის გამორთვა, ხმის სიმაღლე და ენის გადართვა. პარამეტრებში: ქალის/კაცის ხმა, სისწრაფე, ტექსტის ზომა, ორიგინალის ჩვენება, მუქი/ღია თემა და „ეკრანი არ ჩაქრეს“.

**ღონისძიებამდე** სცადეთ ტელეფონით დაკავშირება სწორედ დარბაზის Wi-Fi-ზე (იხ. [პრობლემების გადაჭრა](#პრობლემების-გადაჭრა)).

## პარამეტრები: მიკროფონი, ხმა, ლექსიკონი

სპიკერის გვერდზე, ზედა მარჯვენა კუთხეში ღილაკი **პარამეტრები**:

| განყოფილება | რა შეიძლება |
|---|---|
| **შესასვლელი (მიკროფონი)** | მოწყობილობის არჩევა (USB მიკროფონი, მიქსერი, ყურსასმენი), **გაძლიერება** 25–400%, ხმის დონის ზოლი, **ხმაურის ჩახშობა**, **ექოს ჩახშობა**, **ავტომატური ხმის დონე** (მიქსერის/პულტის შემთხვევაში გამორთეთ) |
| **გამოსასვლელი (ამ კომპიუტერზე)** | თარგმანის ხმით დაკვრა თავად სერვერის კომპიუტერზე: მოწყობილობის არჩევა (დარბაზის დინამიკები, FM/ინფრაწითელი თარგმანის სისტემა), ხმის სიმაღლე, ქალის/კაცის ხმა |
| **თარგმანი** | ხმოვანი თარგმანის სისწრაფე ყველა მსმენელისთვის, ჩართული სიტყვების („ეეე“, „ამმ“, „და და“) გაწმენდა, **ლექსიკონი** |
| **სისტემა** | თემა, თარგმანის სტატისტიკა (დრო, შეცდომები), **სერვერის გამორთვა** |

მიკროფონის არჩევა ამოცნობისთვის მუშაობს **Chrome 135-ზე და უფრო ახალზე**. ძველ Chrome-ში ამოცნობა სისტემის ნაგულისხმევ მიკროფონს იყენებს.

### ლექსიკონი

ერთი წესი ერთ ხაზზე, `რაც ისმის = რაც უნდა იყოს`:

```
დარბაზი = Darbazi
ჯიპიტი = GPT
ხელოვნური ინტელექტი = AI
hall = Darbazi
```

- **ქართული წესი** ასწორებს ამოცნობილ ტექსტს თარგმნამდე. ბრუნვის დაბოლოებებსაც იჭერს: `დარბაზი = Darbazi` ასევე აქცევს „დარბაზში“-ს „Darbazi-ში“-დ, რასაც Google თარგმნის როგორც „in Darbazi“.
- სახელი, კომპანია ან ტერმინი **ლათინურად** თუ ჩაწერეთ, Google მას აღარ თარგმნის (მაგ. „დარბაზი“ აღარ გახდება „hall“).
- **ინგლისური წესი** ასწორებს ინგლისურ თარგმანს.
- `#`-ით დაწყებული ხაზი კომენტარია. ლექსიკონი ინახება `settings.json`-ში და სერვერის გადატვირთვის შემდეგაც რჩება.

## როგორ მუშაობს (სინქრონული თარგმანი, Wordly-ს პრინციპით)

1. Chrome ამოიცნობს ქართულ მეტყველებას და სპიკერის გვერდი სერვერს **მთელ მიმდინარე ფრაზას** უგზავნის, როგორც კი ის იზრდება (წამში ~4-ჯერ).
2. სერვერი ([simul.py](simul.py)) ყოველ ჯერზე **მთელ ფრაზას თავიდან თარგმნის**. ასე Google ხედავს სრულ კონტექსტს, მათ შორის ქართულ ზმნას, რომელიც ბოლოს მოდის.
3. ინგლისური სიტყვა მსმენელთან მიდის მხოლოდ მაშინ, როცა **ზედიზედ რამდენიმე თარგმანი მასზე თანხმდება** (Local Agreement). ასე არასტაბილური „ვარაუდები“ არ ჟღერდება.
4. უკვე ნათქვამი სიტყვები ახალ თარგმანს ედარება და მხოლოდ **ახალი ნაწილი** ჟღერდება. ამიტომ სიტყვები აღარ მეორდება, მაშინაც კი, როცა Google წინადადებას გადააწყობს.
5. ხმა (Microsoft neural, `edge-tts`) იქმნება წინასწარ გახსნილი კავშირით (~0.3 წმ). მსმენელთან ჩუმი თავი და ბოლო იჭრება და ნაწილები უწყვეტად უკრავს.
6. თარგმნამდე ტექსტი სუფთავდება („ეეე“, „და და“) და ლექსიკონის წესები ესადაგება. ერთი და იგივე ტექსტი ყოველთვის ერთნაირად ითარგმნება (ქეში), რაც თანხმობას სტაბილურს ხდის.
7. სერვერი Google Translate-ის რამდენიმე მისამართს იყენებს: ჯერ ყველაზე სწრაფს, ~0.35 წამში პასუხის გარეშე პარალელურად მეორეს. შეზღუდულ (HTTP 429) მისამართს რამდენიმე წუთით გვერდზე დებს. თარგმანი თუ წინადადების ბოლოს მაინც ვერ მოვიდა, წინადადება ბოლო მიღებული თარგმანით იხურება და არ იკარგება.
8. Chrome-ის ამოცნობა ზოგჯერ „ჩართული“ რჩება, მაგრამ შედეგს აღარ აბრუნებს. სპიკერის გვერდი ამას მიკროფონის დონით ამჩნევს (ხმა ისმის, ტექსტი არ მოდის) და ამოცნობას თავიდან რთავს.

მსმენელი ხედავს დადასტურებულ თარგმანს და ბაცი ფერით მის გაგრძელებას, რომელიც ჯერ კიდევ შეიძლება შეიცვალოს.

### რეჟიმები (სპიკერის გვერდზე)

| რეჟიმი | თანხმობა | დაყოვნება* | ხარისხი |
|---|---|---|---|
| ⚡ სწრაფი | 2 თარგმანი | ~0.5–1 წმ | ზოგჯერ უხეში |
| **ბალანსი** (რეკომენდებული) | 3 თარგმანი, ბოლო სიტყვის შეკავება | ~0.7–1.3 წმ | თითქმის სრული წინადადების თარგმანის დონე |
| ხარისხიანი | 3 თარგმანი, 3 სიტყვის შეკავება | ~2–4 წმ | საუკეთესო |

თუ მსმენელი ჩამორჩება, დაკვრა ჩქარდება 1.35x-მდე ტონის შეცვლის გარეშე. 8 წამზე მეტით ჩამორჩენისას ძველი ნაწილები გამოიტოვება.

## შეზღუდვები (დემოსთვის)

- სპიკერის გვერდი მიკროფონს მხოლოდ `localhost`-ზე ან `https`-ზე იღებს, ამიტომ სპიკერი სერვერის კომპიუტერზე უნდა იყოს. ამავე მიზეზით, მართვის მოთხოვნები (ტექსტის გაგზავნა, გასუფთავება, პარამეტრები) მხოლოდ ამ კომპიუტერიდან მიიღება: Wi-Fi-ზე მყოფ სხვა მოწყობილობას მსმენელებისთვის ტექსტის გაგზავნა არ შეუძლია.
- საჭიროა ინტერნეტი (Chrome-ის ამოცნობა, თარგმანი და ხმა ღრუბლოვანი სერვისებია).
- ფრაზის ხელახალი თარგმნა Google-ს წამში ~4 მოთხოვნას უგზავნის. Google ზოგიერთ მისამართს რამდენიმე წუთში ზღუდავს; სერვერი ამ დროს სხვაზე გადადის, მაგრამ ყველა ერთად თუ შეიზღუდა, თარგმანი შეფერხდება.
- Google Translate-ის და edge-tts-ის ეს ენდპოინტები არაოფიციალურია. პროდაქშენისთვის: Google Cloud Speech/Translation, Azure Speech Translation ან მსგავსი.

## ინსტალერის აწყობა (დეველოპერისთვის)

ინსტალერებს GitHub Actions აწყობს ([.github/workflows/build.yml](.github/workflows/build.yml)):

- **ახალი ვერსიის გამოშვება:** `server.py`-ში შეცვალეთ `VERSION`, შემდეგ `git tag v1.2.0 && git push --tags`. დაახლოებით 10 წუთში [Releases](https://github.com/Darbazi-A/live-translate/releases)-ში გამოჩნდება Windows-ის `Setup.exe` და macOS-ის `.dmg`.
- **ტესტური აწყობა გამოშვების გარეშე:** GitHub → **Actions → Build installers → Run workflow**. ფაილები ჩამოიტვირთება გაშვების გვერდის **Artifacts**-დან.
- **ლოკალურად:** `pip install -r requirements.txt pyinstaller`, შემდეგ `pyinstaller packaging/LiveTranslate.spec` (შედეგი `dist/`-ში). Windows-ზე Setup.exe-სთვის საჭიროა [Inno Setup](https://jrsoftware.org/isinfo.php): `ISCC packaging\windows\LiveTranslate.iss`.
- ხატულები: `python packaging/make_icons.py`.

დაყენებულ ვერსიაში პარამეტრები და ჟურნალები ინახება: Windows `%APPDATA%\LiveTranslate`, macOS `~/Library/Application Support/LiveTranslate`.
